Drift

See where the build drifts from your design system.

Drift is a Chrome extension for product designers. Pick any section of a live web app, and Drift lists every place where its rendered styles don't match your design tokens, each with a screenshot and a plain-language comment.

How it works

  1. Add your design system once. Colours (light and dark), typography, spacing, radius and component specs, as JSON from your Figma export: plain, Tokens Studio or W3C design tokens.
  2. Pick a section of the page. Clicks never reach the app while you pick, so a stray click can't place an order.
  3. Run the diagnosis. A rule-based check compares every colour, font, padding and radius with your tokens. With your own Anthropic API key, Claude then reviews the findings, dismisses false alarms and catches component issues, such as a toggle built at the wrong size.
  4. Share it. Each issue comes with a cropped screenshot, the found and expected values, the token to use and a fix for developers. Copy it as text, download one HTML report, or add it to a Google Doc, one report below the other.

What it checks

  • Colours outside the current theme's palette, including near misses that look hardcoded
  • Dark-theme colours used in light mode, and the reverse
  • Font families, sizes, weights and line heights off the type scale
  • Padding, gaps and corner radii off the spacing and radius scales
  • Components that don't match their specs (with Claude)

Privacy

Drift has no server and no analytics. Settings and your API key stay in Chrome on your computer. Page data goes to Anthropic only if you add your own key, with digits masked in text by default. Google access is limited to the files Drift creates, unless you choose your own doc. Read the privacy policy.
